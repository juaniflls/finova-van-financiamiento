# Contribuir a FINOVA

Las mejoras son bienvenidas.

## Flujo recomendado

1. Cree un fork del repositorio.
2. Cree una rama descriptiva.
3. Realice cambios pequeños y verificables.
4. Compruebe que `index.html` abre correctamente.
5. Si modifica la matemática, documente el cambio en `docs/METODOLOGIA.md`.
6. Abra un Pull Request explicando:
   - qué cambia;
   - por qué;
   - cómo se validó.

## Ideas para futuras versiones

- Impuestos.
- Capital de trabajo.
- Depreciación.
- Valor residual.
- Escenarios probabilísticos.
- Monte Carlo.
- Comparación entre varios proyectos.
- Exportación de reportes.
- Gráficos adicionales.
- Internacionalización.

## Principio de diseño

La aplicación debe mantener una regla básica:

> La sofisticación matemática solo es útil si el usuario puede entender de dónde sale el resultado.
