3. Calcular el VAN con financiamiento

Descuento de los flujos ajustados al costo de fondos elegido.

Metodología de clase

Estructura matemática

Flujo neto_t = Ingresos_t − Gastos_t Monto financiado = Inversión × % financiamiento Cuota periódica = P × i / [1 − (1+i)^(-n)] Flujo de caja_t = Flujo neto_t − Cuotas_t Flujo ajustado_t = Flujo de caja_t + Capital_t = Flujo neto_t − Interés_t VP_t = Flujo ajustado_t / (1+k)^t VAN = − Inversión inicial + Σ VP_t
