# Changelog

Todas las modificaciones relevantes de FINOVA se documentarán en este archivo.

## [1.0.0] — 2026-10-06

### Añadido

- Aplicación HTML autónoma.
- Evaluación de VAN con financiamiento.
- Cuota nivelada con sistema francés.
- Separación entre interés y capital.
- TIR del flujo ajustado.
- Payback descontado.
- Tabla anual de amortización.
- Auditoría completa del cálculo.
- Sensibilidad de ingresos y gastos.
- Puntos de equilibrio cuantitativos.
- Recomendaciones automáticas.
- Modo exposición.
- Exportación de escenarios en JSON.
- Notebook reproducible.
- Documentación para publicación en GitHub Pages.
